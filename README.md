# Data-Analysis-Dashboard-sales
This project focuses on analyzing sales data to derive actionable insights by the help of MySQL and  Power BI.
#project objective
This Power BI project provides a comprehensive Sales Dashboard designed to offer insights into sales performance across multiple dimensions. Key features include:

Sales Analysis by Year and Location: Visualize revenue, sales, and quantity trends across different years and geographic locations.

Top 5 Customers by Revenue: Identify the most profitable customers by total revenue.

Revenue Analysis by Year, Quarter, and Month: Track revenue fluctuations over time, breaking down performance by year, quarter, and month.

Market Sales Overview: Gain a deeper understanding of sales performance by market segment.

This project aims to deliver actionable insights through interactive and visually engaging reports, enabling users to make data-driven decisions and optimize sales strategies.
